动态图表版模型对比

这里把适合动的 7 类图都做出来：排名轨迹、成对差值、预测播放、热力图 reveal、Pareto 轨迹、残差分布切换、胜场累积。动画只服务于“变化过程”，不做无意义装饰。

数据口径
全部来自 full_benchmark_v2_cmatrix_hmatrix_s3 的真实 metrics/predictions CSV。每个动画都可以暂停，避免为了动而牺牲读数。

1. Animated Rank Trajectory

模型排名随 context/horizon 变化。线越靠上排名越好。

2. Animated Paired Delta

TabPFN-TS 与该 task 最强非 TabPFN baseline 的差值，低于 0 表示 TabPFN-TS 更好。

3. Forecast Playback

真实曲线固定，预测线按 horizon step 展开。

4. Heatmap Reveal

Run × Model 排名热力图按场景逐步出现。

5. Efficiency / Performance Pareto

点随场景移动，显示推理时间和排名的 trade-off。

6. Residual Distribution Morph

残差分布随场景切换，观察误差是否集中或偏移。

7. Cumulative Wins Race

按 task 顺序累计第一名次数，展示谁是持续赢。
